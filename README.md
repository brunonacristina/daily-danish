# Daily Danish

Páginas estáticas de estudo de dinamarquês geral e logística. Comece por index.html e faça uma sessão por dia de estudo, com limite de 30 minutos.

## Publicação
No GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
A ativação depende de uma pessoa com acesso administrativo. O site só deve ser anunciado como disponível após verificar sua publicação.

## Privacidade e áudio
Este repositório é destinado somente a material didático genérico. Respostas ficam no localStorage do navegador e não são enviadas ao repositório. Copie-as manualmente para o chat para correção.
O TTS do Google recebe somente o texto didático solicitado. Se falhar, a página oferece uma voz dinamarquesa do dispositivo, quando disponível.

## Desenvolvimento
Leia AGENTS.md antes de alterar. Cada página de aula inclui seu próprio CSS e JavaScript. Preserve os IDs e as chaves de armazenamento em futuras atualizações.
